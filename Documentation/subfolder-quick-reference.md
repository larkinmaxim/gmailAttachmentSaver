# Quick Start: Subfolder Selection Feature

## 🚀 3-Step Process

### 1️⃣ Select Attachments
Check the boxes next to attachments you want to save

### 2️⃣ Choose Destination
Select subfolder from dropdown:
- **Project Root** - Main project folder
- **01_System_Design** - Technical specs
- **02_Meet_Recordings** - Meetings
- **03_Correspondence** - Emails
- **04_Project_Documentation** - General docs
- **Project_Management** - Project plans
- **Carrier_Onboarding** - Onboarding

### 3️⃣ Save
Click "💾 Save to PMO Folder"

---

## 📁 Folder Guide

| Folder | Use For | Example Files |
|--------|---------|---------------|
| 📋 **Project Root** | Quick saves, mixed files | Any file type |
| 📁 **01_System_Design** | Technical documentation | Architecture docs, UML diagrams, API specs |
| 📁 **02_Meet_Recordings** | Meeting materials | Recordings, notes, transcripts |
| 📁 **03_Correspondence** | Email attachments | Email PDFs, correspondence files |
| 📁 **04_Project_Documentation** | Project deliverables | Reports, documentation, presentations |
| 📄 **Project_Management** | Management docs | Plans, timelines, schedules |
| 🚀 **Carrier_Onboarding** | Onboarding materials | Setup guides, onboarding docs |

## ✅ What Happens

✨ **Automatic** - Folders created if they don't exist  
✨ **Smart** - Uses existing folders, no duplicates  
✨ **Safe** - Falls back to project root if issues occur  
✨ **Clear** - Get detailed notification with results  

---

## 💡 Tips

**Tip 1**: Use **Project Root** when unsure  
**Tip 2**: Folders are created automatically - no setup needed  
**Tip 3**: Check notification for exact save location  
**Tip 4**: Files saved to subfolders appear in PMO project folder structure  

---

## ❓ Questions

**Q: Will my old saves still work?**  
A: Yes! Everything works as before.

**Q: What if I don't select a subfolder?**  
A: Saves to Project Root (default).

**Q: Can I move files later?**  
A: Yes, in Google Drive as normal.

**Q: What if folder creation fails?**  
A: System falls back to Project Root automatically.

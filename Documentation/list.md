### 🔧 Implemented Environment Variables

1. **TRIMBLE_AUTH_SERVER_TOKEN** - Your Trimble auth server token for OAuth
2. **PMO_WEBHOOK_URL** - PMO webhook endpoint URL
3. **TRIMBLE_OAUTH_URL** - Trimble OAuth server endpoint
4. **DEFAULT_JIRA_URL** - Default Jira instance URL
5. **OAUTH_GRANT_TYPE** - OAuth grant type (**client_credentials**)
6. **OAUTH_SCOPE** - OAuth scope (**Agentic-N8N-Webhook**)
7. **SETTINGS_STORAGE_KEY** - Storage key for user settings (**JIRA_SETTINGS**)
